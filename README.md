# Power BI E-Commerce Executive Dashboard

This repository contains the data generation scripts, DAX measures, and documentation for a comprehensive Power BI project. This project demonstrates advanced Business Intelligence capabilities, transforming raw e-commerce transaction data into a highly interactive executive dashboard.

## Project Overview
The dashboard is designed for C-level executives to monitor business health, track revenue growth, and analyze supply chain logistics.

### Key Features Demonstrated:
1. **Advanced DAX Formulation:** Implementation of Time Intelligence functions (YTD, MoM Growth) and dynamic filtering logic.
2. **Relational Data Modeling:** A Star Schema design connecting Sales, Products, Customers, and a dynamic Calendar Table.
3. **Data Visualization:** KPI cards, waterfall charts for revenue breakdown, and geospatial mapping for logistics tracking.

## Repository Contents
* `generate_sample_data.py`: A Python script using Pandas to generate a synthetic e-commerce dataset (Orders, Customers, Products). Run this script to generate the CSVs for Power BI.
* `DAX_Measures.dax`: A text file containing all the advanced DAX code used in the dashboard.
* `PowerBI_Build_Guide.md`: Step-by-step instructions on how to model the data and build the dashboard visuals.
